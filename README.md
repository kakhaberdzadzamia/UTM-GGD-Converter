## 📌 ძირითადი ფუნქციონალი (Features)
- **WGS84 ↔ GGD ტრანსფორმაცია:** ოფიციალური NAPR / IGN Bursa-Wolf 7 პარამეტრის გამოყენება (ფიქსირებული ეპოქა 2011.353, ITRF2008 / GRS80).

- **მასშტაბის კოეფიციენტები (Scale Factors):**
  - ბადის მასშტაბი ($k$)
  - სიმაღლის მასშტაბი ($k_h$)
  - კომბინირებული მასშტაბი ($CSF = k \cdot k_h$)
- **მასიური კონვერტაცია (Excel Bulk Processing):** `.xlsx` და `.csv` ფაილების ატვირთვა და შედეგების ექსპორტი.
- **სრულიად ავტონომიური (Client-side):** მუშაობს უშუალოდ მომხმარებლის ბრაუზერში, სერვერზე მონაცემების გაგზავნის გარეშე.
